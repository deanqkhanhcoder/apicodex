Tài liệu kỹ thuật

Hướng dẫn setup Codex config cho người mới

Thiết lập biến môi trường và nạp file config.toml để sử dụng API Key riêng biệt trên ứng dụng Codex. Lịch sử chat và quy trình làm việc trên Codex được giữ nguyên, không bị ảnh hưởng.

Thời gian thiết lập: ~3 phút Nền tảng: Windows, macOS, Linux Xem Google Docs gốc ↗

Lưu ý quan trọng
  • Endpoint mẫu hiện dùng HTTP, không mã hóa đường truyền. Yêu cầu địa chỉ HTTPS được xác nhận trước khi truyền API Key hoặc dữ liệu nhạy cảm. Model và tùy chọn trong mẫu cần được đối chiếu với phiên bản ứng dụng và dịch vụ đang dùng.
  • Không gửi hoặc chia sẻ API key cho người khác. API key giống như mật khẩu.
  • Sau khi cấu hình thành công, yêu cầu sử dụng model sẽ trừ token từ API key được cấp, không dùng hạn mức Codex của tài khoản cá nhân.
  • Lịch sử chat và quy trình làm việc trên Codex được giữ nguyên, không bị ảnh hưởng.
01

Bước 1: Đăng nhập Codex

Mở ứng dụng Codex và đăng nhập bằng tài khoản OpenAI/Codex cá nhân của bạn.

Lưu ý: Không đăng nhập bằng tài khoản OpenAI EDU. Nếu đang sử dụng tài khoản EDU, hãy đăng xuất và chuyển sang tài khoản khác trước khi tiếp tục.
02

Bước 2: Thiết lập API Key

Chọn môi trường bạn đang sử dụng để lưu biến môi trường CODEX_LB_API_KEY:

Mở Command Prompt (CMD) và chạy lệnh sau để lưu API key vĩnh viễn:

setx CODEX_LB_API_KEY "sk-xxxxxxxxxxxxxxxx"

Sau đó, đóng CMD hiện tại, mở cửa sổ CMD mới và kiểm tra lại:

echo %CODEX_LB_API_KEY%

Nếu màn hình hiển thị API key là đã thiết lập thành công.

Mở PowerShell và chạy lệnh sau:

[Environment]::SetEnvironmentVariable("CODEX_LB_API_KEY", "DÁN_API_KEY_VÀO_ĐÂY", "User")

Đóng PowerShell, mở lại cửa sổ mới và kiểm tra:

$env:CODEX_LB_API_KEY

Nếu màn hình hiện API key là đã thành công.

Mở Terminal và thực hiện lần lượt các bước:

echo 'export CODEX_LB_API_KEY="DÁN_API_KEY_VÀO_ĐÂY"' >> ~/.zshrc source ~/.zshrc echo $CODEX_LB_API_KEY

Nếu Terminal hiển thị API key là thành công.

Kiểm tra shell đang dùng bằng lệnh echo $SHELL:

Nếu là Bash (/bin/bash), chạy:

echo 'export CODEX_LB_API_KEY="DÁN_API_KEY_VÀO_ĐÂY"' >> ~/.bashrc source ~/.bashrc echo $CODEX_LB_API_KEY

Nếu là Zsh (/bin/zsh), chạy:

echo 'export CODEX_LB_API_KEY="DÁN_API_KEY_VÀO_ĐÂY"' >> ~/.zshrc source ~/.zshrc echo $CODEX_LB_API_KEY
03

Bước 3: Mở file config

Windows

Mở CMD và chạy lệnh sau (nếu chưa có thư mục .codex, hãy tạo thư mục trước):

notepad %USERPROFILE%\.codex\config.toml

macOS

Mở Terminal và chọn một trong hai cách:

Dùng TextEdit:

open -e ~/.codex/config.toml

Hoặc dùng Terminal:

nano ~/.codex/config.toml

Linux

Tạo thư mục nếu chưa có và mở file config bằng lệnh:

mkdir -p ~/.codex && nano ~/.codex/config.toml
04

Bước 4: Cập nhật nội dung config

Sao lưu file config.toml hiện có trước khi thay đổi. Đối chiếu mẫu dưới đây với cấu hình của bạn, chỉ thay các mục cần thiết rồi lưu lại; không xóa các thiết lập riêng chưa được sao lưu:

config.toml 
# ==================================================
# Model
# ==================================================

model = "gpt-6-astra"
model_provider = "codex-lb"

sandbox_mode = "workspace-write"
approval_policy = "on-request"

model_reasoning_effort = "ultra"
personality = "pragmatic"
service_tier = "priority"

approvals_reviewer = "user"

[desktop]
followUpQueueMode = "queue"
conversationDetailMode = "STEPS_COMMANDS"

enabled-reasoning-efforts = [
   "low",
   "medium",
   "high",
   "xhigh",
   "ultra",
   "max"
]

show-context-window-usage = true


# ==================================================
# Windows
# ==================================================

[windows]
sandbox = "elevated"


# ==================================================
# Model Provider
# ==================================================

[model_providers.codex-lb]
name = "openai"
base_url = "http://apicodex.cloud-ip.cc:2455/backend-api/codex"
wire_api = "responses"
env_key = "CODEX_LB_API_KEY"
supports_websockets = true
requires_openai_auth = true


# ==================================================
# Subagent
# ==================================================

[agents.subagent]
model = "gpt-5.6-terra"


# ==================================================
# Plugins
# ==================================================

[plugins."browser@openai-bundled"]
enabled = true

[plugins."chrome@openai-bundled"]
enabled = true

[plugins."visualize@openai-bundled"]
enabled = true

[plugins."codex-app-tools@openai-bundled"]
enabled = true

[plugins."documents@openai-primary-runtime"]
enabled = true

[plugins."pdf@openai-primary-runtime"]
enabled = true

[plugins."spreadsheets@openai-primary-runtime"]
enabled = true

[plugins."presentations@openai-primary-runtime"]
enabled = true

[plugins."template-creator@openai-primary-runtime"]
enabled = true

[plugins."computer-use@openai-bundled"]
enabled = true


# ==================================================
# Features
# ==================================================

[features]
js_repl = false
memories = false
chronicle = false

[memories]
generate_memories = false
use_memories = false

Lỗi không nhận API Key

Windows

Cần đóng Terminal cũ và mở Terminal mới để kiểm tra lại bằng lệnh echo %CODEX_LB_API_KEY%. Nếu chưa nhận, hãy chạy lại lệnh setx và khởi động lại Terminal.

macOS / Linux

Chạy lệnh source ~/.zshrc (hoặc source ~/.bashrc). Mở file shell tương ứng để kiểm tra chắc chắn có dòng export CODEX_LB_API_KEY="API_KEY_CỦA_BẠN".
