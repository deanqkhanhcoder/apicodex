Câu hỏi thường gặp

Giải đáp nhanh về kích hoạt token, model hỗ trợ và kênh chăm sóc khách hàng.

Bắt đầu và nhận API Key thế nào?

Chọn gói nạp phù hợp trong bảng giá, liên hệ Zalo 0899759653 để nhận API Key riêng và làm theo hướng dẫn cấu hình nhanh trong 3 phút.

Thời hạn và cách gia hạn gói token?

Mỗi gói có thời hạn sử dụng 30 ngày kể từ ngày kích hoạt. Bạn có thể theo dõi số dư và hạn mức trực tiếp trên Portal tra cứu và gia hạn hoặc nâng gói linh hoạt bất kỳ lúc nào qua Zalo.

Hệ thống hỗ trợ những model OpenAI nào?

API Codex hỗ trợ danh mục model OpenAI mới nhất (gpt-6-astra, gpt-5.6-terra, gpt-4o), mở khóa toàn bộ plugin, browser và subagent trên ứng dụng Codex.

Lỗi 401, 429 hoặc cần hỗ trợ kỹ thuật?

Với 401, kiểm tra lại key và biến môi trường. Với 429, chờ reset hạn mức ngày. Đội ngũ kỹ thuật hỗ trợ trực tiếp qua Zalo để kiểm tra cấu hình và cấp lại key nhanh chóng.

Có thể sử dụng API Codex trên những nền tảng nào?

Tương thích mượt mà với ứng dụng Codex trên Windows, macOS, Linux, đồng thời hỗ trợ Kiro, Cursor, Antigravity và mọi công cụ lập trình AI hỗ trợ custom OpenAI endpoint.

Kênh liên hệ và cộng đồng hỗ trợ?

Hỗ trợ chính thức qua Zalo 0899759653 và nhóm cộng đồng, giải đáp thắc mắc và hướng dẫn cấu hình chi tiết.
